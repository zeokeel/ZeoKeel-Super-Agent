# 交互审计：非技术运营者第一次使用（2026-11-04，只读）

- 角色：产品/运营，不写代码；目标“接活/看进度/处理待办”，不关心架构。
- 证据：`/tmp/r2-*`、`/tmp/r3-*`（修复波前）、`/tmp/r4-*`（修复波后）+ `internal/ui`/`internal/view`/README。
  **注意**：截图来自 demo/测试 harness；r4 里“动作未接线：AttentionAnswerer…”是 harness 缺可选接口，
  生产用 `cmd/zeokeel/wiring_assert.go` 断言已接线，**不计为生产阻断**。未运行 GUI；行为以当前代码为准。
- 结论：单个功能都能解释，但**首次 5 分钟缺少“下一步”与失败恢复**；聊天/审批/IM 接入三处会让运营者卡住或误判。

## P0 / P1 / P2 交互阻断

**P0（首用/核心承诺会失败）**
- **P0-1 输入目标不明 + README 错误指引**：同一个框问答/派活，工作区选中不影响发送（`ui/commands.go:30-34`），
  README:231 却说“先选中工作区再用输入框”；没工作命中时用户不知道是聊天还是派活，任务可能落到别的区。
- **P0-2 审批没有收件箱与提醒**：入口只在总览卡片（`ui/overview.go:51-100`），无导航项、无桌面通知/托盘 badge
  （`ui/tray.go:16-34`），窗口关闭即失联；批准/拒绝无撤销、无批量；审批优先策略下会漏活。
- **P0-3 首跑没有验证与“下一步”**：模型/工作区必填但无标记/无“测试连接”（`ui/onboarding.go:39-152`）；
  来源步骤存 `onboard.*` 却不接线（`runtime/onboarding.go:88-100`）；完成后直接落入运维型总览。
- **P0-4 模型 401 被说成“未配置模型”**：聊天失败回退到确定性文案（`runtime/chat.go:63-90`），用户会去改
  配置而不是检查 key/网络；聊天无重试。
- **P0-5 IM 接入不可自助**：无扫码/设备码/等待/成功/失败状态（`ui/channels.go:205-235`）；DWS 需终端安装登录；
  “DWS/transport/Stream”无用户解释；非技术运营者无法从零接通。

**P1（高频摩擦/误解）**
- 聊天只有单行内联回答与 `Tail(8)` 历史，无展开/复制/重试/停止/历史页（`ui/chat.go:27,44,71,88`）。
- 术语墙：工作区表单“沙箱根/简报/研判/路由”，名词表含 Agent/Thread/Policy/Eval 等架构词（`ui/help.go`）。
- 监控页过载：触发/评估是工程看板；日常应只留总览+执行（截图 r2-trigger/r2-help）。
- 设置页：无搜索/重置/未保存离开提示；密钥不能查看/替换；部署组混 debug 事实 `runtime/pages.go:830-850`。
- 可访问性：faint 文字 2.58:1（白底）/≈3.9:1（深色），10–12px 时间说明；无 focus-visible/reduced-motion
  （`ui/tokens.go:109,139-140`、`ui/stream.go:59`）。
- 视觉：执行/触发行出现 `{?}`/`1'` 占位字形（r4-execution-filter.png、r2-trigger.png）。

**P2（排期）**
- 计数语义重复：顶栏“待处理”、侧栏超级Agent、需要我处理、来源“待审批”各自口径。
- 会话列表无预览/未读/置顶/搜索/右键；每工作区 50 条硬截断。
- 加载态纯文本“等待运行时发布…”，无 skeleton/重试；成功无 toast。
- 状态栏常驻 rev/Go/CGO/SQLite 等 debug 字符串（`ui/chrome.go:141-146`）。

## Top 10 交互修复

1. **给输入框明确“目标”**：自动路由 vs 当前工作区选择（chip/开关），并修 README 的错误指引。
2. **审批收件箱 + 通知/撤销**：导航常驻“待你决定”、托盘 badge/OS 通知、键盘批量、批准/拒绝可撤销。
3. **首跑加验证与最短路径**：必填标记、Test connection、跳过/稍后配置、成功后“下一步”卡片。
4. **IM 授权向导**：扫码/设备码/等待/成功/失败重试、安装与版本检测、可复制命令/打开终端。
5. **聊天恢复真实错误**：401/超时明确提示+重试；不要再显示“未配置模型”。
6. **聊天历史与消息操作**：可展开回答、复制/重试/停止、历史页（超过 8 条可查）。
7. **术语清理**：主 UI 只留用户词；架构词收进高级/名词表折叠。
8. **监控收口**：日常只留总览+执行；触发/评估移到高级；失败/等待进入“待你决定”。
9. **工作区流程**：首跑用原生选择器、解释 root/kind/purpose、创建成功引导“新建会话”，允许改路径/类型。
10. **视觉与可访问性**：修 `{?}` 图标、提升 faint 对比度、focus ring、reduce-motion、跟随 OS 字号。

## 建议从主 UI 移除（无历史包袱）

- 侧栏“触发”“评估”两页 → 收到“高级/诊断”；“消息”可并入执行详情。
- 设置›部署里的日志路径、备份/归档命令、退出码、health、OS/时区 debug 事实 → About/诊断。
- 状态栏的版本/rev/Go/CGO/SQLite/“一条连续的上下文” → About。
- “配置 rev”“来自 SQLite·kv”“动作未接线：<接口名>”等实现细节。
- 名词表里的 Agent/Main Session/Executor Session/Policy/Eval 等架构词默认折叠。
- 多套重复计数 badge（保留一个“待你决定”主入口）。

## 保留的优点

- 禁用渠道标“未启用”、空态直接说“没有需要你处理的事”，不假装在线/不假成功。
- 删除工作区确认说明“移除面板记录，不删磁盘目录”，失败时说明数量。
- 审批行信息完整（来源/谁/原话/要做/产出/敏感项/时间），批准/拒绝就地完成。
- 原生目录选择器异步不卡帧；重复根目录/非法路径服务端拒绝。
- 回答内联在输入框上方且“已回答不标红”，方向正确。
- ⌘K 搜索、Esc 关闭、深浅色跟随系统；工作区树与执行页的阶段过滤清晰。
